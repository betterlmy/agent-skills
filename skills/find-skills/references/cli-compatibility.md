# CLI 兼容性

<!-- cli-compatibility-contract:v1 -->

| 字段 | 值 |
| --- | --- |
| 工具 | Skills CLI |
| 分发标识 | `skills`（通过 `npx skills` 调用） |
| 本机验证版本 | 未安装，当前没有本机验证版本 |
| 验证日期 | `2026-07-30` |
| 版本策略 | 本机安装并验证前，不声明当前命令集的支持范围 |

`npx --no-install skills --help` 在本机未找到已安装包。注册表返回的候选版本不属于本机版本，不能作为已验证基线。

## 关键能力

在不触发下载的前提下先运行：

```bash
npx --no-install skills --help
```

只有 `find`、`add`、`check`、`update` 和任务所需选项实际出现在帮助中，才能使用对应路径。安装、全局写入和跳过确认分别是不同授权边界。

## 版本不一致时

- 本机已有版本且命令存在：记录实际版本或包版本，再继续执行。
- CLI 不提供版本命令：记录包管理器中的本地安装版本和帮助输出，不伪造语义版本。
- 本机未安装：可以继续网页或仓库检索；需要 `npx` 下载时先获得用户同意。
- `add`、`update` 或 `-g -y` 会修改用户环境，必须由用户明确授权。
