# Mermaid Diagrams 技能包

使用 Mermaid 声明式文本语法创建专业、规范的软件设计图表。本 Skill 助力开发者与架构师可视化系统架构、记录代码类结构、建立数据库实体模型并高效传递技术方案。

## 核心目标

将复杂的软硬件技术架构转化为清晰、易于维护、可随源码一同纳入 Git 版本控制的图表资产。Mermaid 能够依据轻量文本定义进行跨平台渲染，使团队能够在 Pull Request 评审、技术 Wiki 与工程文档中无缝协作与持续演进。

## 适用场景与触发词

在以下场景使用本 Skill：

- **系统架构设计**：展示系统上下文、容器拓扑、内部组件及部署模型；
- **领域驱动建模（DDD）**：构建包含核心实体、值对象、关联关系与方法行为的领域模型；
- **交互动线推演**：展示 API 接口时序、用户操作旅程、认证握手链路；
- **数据库建模**：梳理数据表拓扑、主外键关联、基数约束与字段 Schema；
- **流程与算法梳理**：绘制业务流转规则、逻辑决策树、复杂算法分支与 CI/CD 构建流水线；
- **方案沟通协同**：在编码实施前统一各方对核心技术决策的共识。

## 9 大核心图表类型支持

1. **类图（Class Diagrams）**：领域建模、面向对象类层级设计与实体依赖关系；
2. **时序图（Sequence Diagrams）**：API 交互、用户操作流与多系统时间时序调用；
3. **流程图（Flowcharts）**：用户动线、业务审批流、分支决策逻辑与构建流水线；
4. **实体关系图（ERD）**：数据库表结构、主外键约束与数据建模；
5. **C4 架构图（C4 Diagrams）**：系统上下文视图、容器视图与组件视图；
6. **状态图（State Diagrams）**：状态机模型、复杂对象生命周期变迁；
7. **Git 分支图（Git Graphs）**：分支演进策略、合并与发布工作流；
8. **甘特图（Gantt Charts）**：项目开发排期与关键里程碑规划；
9. **饼图 / 柱状图（Pie/Bar Charts）**：数据度量与比例可视化展示。
