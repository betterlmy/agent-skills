# CLI 兼容性

| 字段 | 值 |
| --- | --- |
| 工具 | Mermaid CLI (`mmdc`) |
| 分发标识 | `@mermaid-js/mermaid-cli` |
| 本机验证版本 | 未安装，当前没有本机验证版本 |
| 验证日期 | `2026-07-30` |
| 版本策略 | 在本机完成版本与渲染验证前，不声明支持范围 |

没有本机版本时，不得把文档示例描述为已验证结果，也不要记录从注册表查询到的版本作为“本机版本”。

## 关键能力

获得用户安装授权后，依次检查：

```bash
mmdc --version
mmdc --help
mmdc -i minimal.mmd -o minimal.svg
```

最小图应覆盖当前任务使用的图类型、frontmatter、主题或布局。宿主平台内置 Mermaid 渲染器与 `mmdc` 可能不是同一版本，必须分别验证。

## 版本不一致时

- 能输出版本但最小图失败：按渲染失败处理，不能仅凭版本号继续。
- 语法由宿主平台渲染：以目标平台实际渲染结果为准。
- `mmdc` 未安装：交付 Mermaid 源码或使用用户已授权的其他渲染路径。
- 安装、拉取 Docker 镜像或访问在线编辑器前，遵循用户授权和网络边界。
