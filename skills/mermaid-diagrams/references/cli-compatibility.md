| 版本策略 | 记录已验证版本，以实际能力探测和最小渲染决定其他版本能否继续 |

`11.16.0` 已完成版本和帮助探测，并从一份 Markdown 文档提取 `flowchart` 与 `stateDiagram-v2` 两张图生成 SVG。该结果只证明上述环境和图类型的本机 CLI 路径可用，不代表其他 Mermaid 版本、图类型、主题、布局或宿主平台内置渲染器已经验证。

## 关键能力

命令行导出前依次检查；若 `mmdc` 未安装，先按下方授权边界处理：

```bash
mmdc --version
mmdc --help
mmdc -i minimal.mmd -o minimal.svg
mmdc -i document.md -o rendered.md -a artefacts
```

最小图必须覆盖当前任务实际使用的图类型；使用 Markdown 多图提取、frontmatter、主题、布局或非 SVG 输出时，还要分别覆盖对应参数。命令成功后确认输出文件存在、格式正确且非空。宿主平台内置 Mermaid 渲染器与 `mmdc` 可能不是同一版本，必须分别验证。

## 版本不一致时

- 版本与 `11.16.0` 一致：仍需运行帮助探测和与当前任务匹配的最小渲染，不能仅凭版本号继续。
- 版本不同但帮助探测和最小渲染成功：可以继续，并报告“版本未经当前基线验证”。
- 能输出版本但最小图或浏览器启动失败：按渲染失败处理，不得无依据增加 `--no-sandbox` 绕过。
- 语法由宿主平台渲染：以目标平台实际渲染结果为准。
- `mmdc` 未安装：交付 Mermaid 源码，或获得用户授权后安装、使用容器或其他渲染路径。
- 安装、拉取 Docker 镜像或访问在线编辑器前，遵循用户授权和网络边界。
