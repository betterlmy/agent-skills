# 安全与敏感信息（核心质量专项）

安全扫描先在用户范围内做脱敏候选发现，再读取鉴权入口、数据边界等必要上下文确认。不得把真实凭证、个人信息或完整请求内容复制到工具输出和报告；局部审计不得为“顺便找秘密”扩大到整个仓库。

## 硬编码凭证

使用整行替换，仅输出位置和脱敏标记：

```bash
rg -n -i --replace '[REDACTED_CREDENTIAL_CANDIDATE]' -e '^.*(password|passwd|secret|api_?key|access_?key|token|private_?key|jwt).*$' --type go -g '!*_test.go'
rg -n --replace '[REDACTED_AWS_ACCESS_KEY]' -e '^.*AKIA[0-9A-Z]{16}.*$' .
rg -n --replace '[REDACTED_PRIVATE_KEY_MARKER]' -e '^.*-----BEGIN.*PRIVATE KEY-----.*$' .
```

- 命中只是候选；区分变量名、测试占位符、公开标识和真实秘密。
- 检查已提交配置文件，但报告只能记录秘密类型与 ` 文件名:行号 `，不能复述值。
- 如果工具或日志已经输出真实秘密，停止扩散并提醒用户按其安全流程轮换和清理；不得擅自删除历史。

## 日志泄密

先只定位候选文件，避免直接打印可能包含真实请求的源码行：

```bash
rg -l -i -e 'log(rus)?\.(Info|Debug|Warn|Error|Print).*request|response|password|token|authorization' --type go
rg -l -e 'fmt\.Print.*(password|token|secret)' --type go
```

读取候选源码后确认：

- 是否打印完整请求、响应、Header、SQL 参数、堆栈或个人信息。
- 是否把内部 `error.Error()` 原样返回给外部调用方。
- 是否存在明确的字段白名单、脱敏函数和生产日志级别约束。

## 加密与随机

- `math/rand` 仅在用于验证码、Token、密钥或其他安全值时才构成阻断级问题；普通模拟或非安全随机不属于该结论。
- 密码使用 MD5/SHA1、固定盐、IV 复用或不安全模式时，结合可达路径和数据类型定级。
- JWT 算法和密钥长度必须依据实际库配置、验证路径与当前安全要求判断。

候选定位：

```bash
rg -n 'math/rand|crypto/md5|crypto/sha1' --type go -g '!*_test.go'
```

## 越权与租户隔离

这类结论必须读取业务逻辑，不能由关键词直接证明：

- 每条数据访问是否绑定当前租户、用户或资源所有者。
- 管理接口是否经过正确的认证与授权链。
- 对象存储预签名 URL、导出和批量接口是否保持租户边界。
- 同级用户互访和普通用户访问管理能力是否被拒绝。

用文本搜索发现鉴权中间件、路由注册和敏感入口候选；再用可用的语义索引、Go 包依赖、源码和测试交叉验证调用链。报告说明每类证据的来源与限制。

## 输入校验与滥用防护

- 路径穿越：外部输入参与路径构造且缺少边界约束。
- SSRF：用户可控 URL 可访问非预期目标。
- 命令注入：外部输入改变可执行文件或参数语义。
- SQL 注入：外部输入进入拼接 SQL；常量拼接不自动构成漏洞。
- 登录、验证码、找回密码等敏感接口缺少与威胁模型匹配的限流、防重放或失败控制。

## 产出

- 已脱敏的凭证候选及确认结果。
- 日志泄密、弱加密或弱随机问题。
- 越权与租户隔离缺口，并附入口、授权检查和数据访问证据。
- 注入、边界校验与滥用防护缺口。
- 未验证假设，以及因权限或环境限制未执行的安全检查。
