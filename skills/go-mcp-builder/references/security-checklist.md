# 网络类 MCP Server 安全检查清单

任何涉及抓取、读取外部网络数据的 MCP tool，开发时必须逐项检查以下五个阶段。

## 阶段 1: URL 验证

- [ ] **长度限制**：URL 超过 2000 字符拒绝访问
- [ ] **http→https 升级**：明文协议自动升级为 TLS
- [ ] **认证凭据剥离**：清除 `user:pass@host` 格式的用户名/密码
- [ ] **已知 URL 规范化**：如 GitHub blob URL → raw.githubusercontent.com

## 阶段 2: 域名安全

- [ ] **白名单/黑名单过滤**：支持子域名匹配
- [ ] **黑名单优先**：同时匹配白名单和黑名单时，拒绝访问
- [ ] **恶意域名检查**：钓鱼网站、恶意软件黑名单（可选）
- [ ] **云端域名验证**：可选接入外部域名安全 API（可选）

## 阶段 3: 网络请求

- [ ] **响应体体积上限**：使用 `io.LimitReader` 限制 10MB，防止 OOM
- [ ] **跨域重定向拦截**：`CheckRedirect` 检测跨域跳转，返回元数据让 LLM 决策
- [ ] **内网地址拦截（SSRF）**：拦截 127/10/172.16/192.168/169.254/localhost
- [ ] **超时设置**：连接超时、TLS 握手超时、响应头超时
- [ ] **本地缓存**：基于 URL 的内存缓存，15 分钟 TTL，`sync.RWMutex` 保护

## 阶段 4: 内容处理

- [ ] **压缩解压**：支持 gzip、deflate（br 可选）
- [ ] **HTML→Markdown 转换**：提供 article（readability 提取）和 full（全量转换）两种模式
- [ ] **内容截断保护**：超过阈值时截断并附加警告标记
- [ ] **分页支持**：start_index / max_length 参数

## 阶段 5: 输出净化（可选，取决于信任边界）

- [ ] **LLM 沙盒摘要**：用子模型摘要外部内容，防止提示词注入
- [ ] **引用长度限制**：直接引用原文不超过 125 字符
- [ ] **版权合规检查**：禁止输出歌词、法律建议等

## 默认安全参数建议

| 参数 | 建议值 |
|------|--------|
| 响应体上限 | 10MB |
| URL 长度限制 | 2000 字符 |
| 缓存 TTL | 15 分钟 |
| 连接超时 | 3 秒 |
| TLS 握手超时 | 3 秒 |
| 响应头超时 | 5 秒 |
| 总超时 | 30 秒 |
| 跨域重定向 | 拦截 |
| http 协议 | 强制升级 https |
| URL 凭据 | 强制剥离 |
