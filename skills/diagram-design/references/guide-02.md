# 2. When to Use

本文为按需设计参考，受 SKILL.md 的任务范围、已有项目约束与授权规则约束；只应用当前需求相关项。节号沿用原指南，可通过入口索引定位。代码示例中的相对脚本/资产路径以 Skill 根目录为准。

Use for any of the 27 visual types (§3) when a reader will learn more from a visual than from prose, a table, or a bulleted list.

**Don't use for:**

- Quick text-only diagrams → use a compact text representation instead.
- Lists of things → table or bullets.
- Simple before/after → table.
- One-shape "diagrams" → just write the sentence.

Before drawing, ask: *Would the reader learn more from this than from a well-written paragraph?* If no, don't draw.
