# 触发评测用例

修改 frontmatter `description` 或任务边界后，逐项判断是否仍符合预期。不要为了命中关键词而扩大范围。

## 应触发

| 提示 | 原因 |
| --- | --- |
| “给我的咖啡品牌 North Pier 做三个原创 SVG logo 方向。” | 从品牌简报创建 SVG Logo |
| “设计一个由字母 QL 组成的 lettermark，要能在 24px 看清。” | 字母标与小尺寸要求 |
| “这是我们现有 logo.svg，帮我调整字标间距并做深色单色版。” | 迭代现有 Logo 与变体 |
| “为 Acme 做图形标加英文名称的横版组合标，直接给 SVG 文件。” | 组合标与 SVG 交付 |
| “我们选了概念 B，请完善竖版、纯图形版和反白版。” | 已选方向的版式扩展 |
| “品牌名是 A&B，做一个安全可嵌入网页的 SVG 字标。” | 用户文本转义与安全 SVG |

## 不应触发

| 提示 | 原因 |
| --- | --- |
| “给设置页画一套 24px 的保存、删除、搜索图标。” | 普通 UI 图标，不是品牌 Logo |
| “把 sales.svg 转成 PNG。” | 单纯格式转换 |
| “用 SVG 画本季度营收柱状图。” | 数据图表 |
| “帮我制定完整品牌战略、品牌声音和年度营销计划。” | 完整品牌战略咨询 |
| “查一下这个 Logo 在美国第 9 类能不能注册。” | 商标法律检索与判断 |
| “用 React 实现这个 SVG Logo 的网站导航栏。” | 网页组件实现，Logo 不是主要产物 |

## 边界行为

- “做一个 app icon，同时也是我们的品牌标记”：若主要目标是品牌识别并需要 Logo 系统，应触发；若只是平台图标切图，不触发。
- “优化现有 SVG Logo 的文件大小”：若需要改变或审查 Logo 图形，应触发；若只是机械压缩或格式转换，不触发。
- “做得像 Apple/Nike 一样”：可触发原创 Logo 设计，但必须拒绝复刻受保护标记，只提取抽象设计属性。
